# IDC/AIDC及算力租赁行业周报研究规则

以公司战略发展部研究员视角回答：行业正在发生什么变化，这些变化怎样影响公司业务，有哪些机会和风险需要提前关注。默认采用北京时间上一完整周星期一00:00至星期日23:59。2026年10月14日、18日更新采用10月5—11日；10月19日采用10月12—18日。

## 研究和选稿

1. 重点检查中国内地及香港、东南亚，同时跟踪有重要影响的全球变化。逐家查询全部已录入媒体，再查官方公告、上市公司披露、政策原文及权威研究机构；媒体的地区栏目不限制全站检索。周报搜索日期单独使用上一完整周，不能用当天日报补查代替。
2. 候选来自完整资料库，不继承首页地区、研究方向、发现列表或21天展示窗口。新闻、公司披露、政策、监管材料、研究报告和数据发布均可进入。按北京时间判断发布日期；跨时区资料核定 `publishedAtBeijing`，数据统计期与发布日期分别保留。
3. 先读原文、日期、署名和统计定义，再判断商业价值。优先考虑影响客户需求、合同收入、现金流、建设成本、交付时间、利用率或竞争格局的增量。官方原件优先于转述，机构观点和作者观点注明归属。旧文中的背景事件不另算本周事件。
4. 按事件ID、原件链接及版本去重；同事件优先保留官方披露，新阶段可作为新事件。不能把融资额、框架协议、储备容量或市场预测直接写成营收、订单或已投运。
5. 所有合格候选逐项记录采用与否和具体理由。正文不设总条数上限，不使用旧 `intelligence.importance` 排名前五。复核国内、东南亚、全球三个方向；存在候选却整组未采用时，须在维护输入中记录取舍原因。不要为填地区配额降低质量。
6. 完成当周研究和交叉比较后再生成周报。网页按钮将已整理的该周研究内容保存为新版；它不执行联网检索，也不自动编造研究判断。新增候选后，重新比较并更新候选取舍记录。另一周的正文不能用于当前周。

## 固定八个板块

1. **本周核心摘要**：3—5项最重要变化，概括新趋势和供管理层快速阅读的结论。
2. **政策与行业环境**：政策、监管、扶持、市场供需及区域变化，重点检查中国与东南亚。
3. **同行企业与重大项目动态**：业务布局、战略调整、融资合作、新建扩建、投产及重大订单，解释商业模式和发展方向。
4. **算力租赁市场与经营数据**：GPU租价、供需、利用率、竞争、机柜及功率、项目容量。注明统计时间、单位、地区、机型及计算口径；连续序列不完整时不计算周涨跌。优先采用可持续跟踪的数据源。
5. **技术进展与上下游产业链**：GPU、服务器、集群、计算架构、液冷、供配电、能源及高功率机柜，解释对成本、效率与交付的影响。
6. **本周重点事件深度分析**：1—3项，写明背景、事件、意义及是否反映趋势或竞争变化。
7. **战略判断与业务启示**：分别考虑现有业务、机会、经营风险、建设、客户、商业模式和布局；给出有依据、可执行的建议，不假设公司已经拥有某项资源或客户。
8. **下周重点跟踪事项**：3—5项，明确原因、待核信息与核实渠道，附本周重要信息原始来源链接。

固定保留全部板块。某板块没有可靠新增信息时，直接填写“本周暂无可靠新增信息。”核心摘要或跟踪事项不足约定数量时，继续筛查已有可靠材料，确无足够材料则在维护字段 `shortfallReason` 记录取舍原因，正文据实保留已有事项，不用重复事件凑数。事实、来源观点与本报告研究判断分别表达；每条重要信息遵循“发生了什么→为什么重要→可能产生什么业务影响”。保持语言专业、通俗，删除无意义状态提示及防御性模板。

## 本地生成与校验

本期输入示例为 `data-candidates/weekly-strategy-20261014.json`。包含 `requestedDate`、`periodStart/periodEnd`、`generatedAt`、`reportIds`、八个固定顺序的 `sections`、全部候选的 `decisions`，以及必要的地区取舍说明 `coverageNotes`。每条正文引用资料ID，事实、来源观点、意义、业务影响、分析与跟踪事项分字段保存。

运行 `node scripts/weekly-update.mjs 输入文件`，校验周期、全部候选取舍、地区遗漏、条数、内容结构和来源引用后写入目录。运行 `node scripts/export-briefs.mjs 输出目录 YYYY-MM-DD` 导出。网页与导出使用同一份保存内容及来源快照。

同周新版追加，不覆盖旧版；相同输入重放幂等。旧半周稿不作为默认版本，历史正文保留原样。历史批次导入兼容旧格式；新版周报通过独立 `weekly-update` 入口生成。资料全量更新若同时请求新版周报，显式设置 `discovery.weeklyFormat: "strategy-v1"` 并在请求中传入该周 `weeklyReview`。

校验、测试、构建后检查桌面和手机阅读、历史选择、生成新版、返回目录和来源链接。当前工程环境使用共享依赖目录，可直接运行 `node scripts/validate-data.mjs`、`node --test --test-isolation=none tests/*.test.mjs`、`node node_modules/vite/bin/vite.js build`。
