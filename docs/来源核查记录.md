## 5. 影响使用的主要限制

- GPU 价格：SMM 的基准/零售价格、现货成交指数、挂牌价和跨卡型综合指数不能混用；两篇方法公告仍需原文复核。Mysteel 混合样本说明来自检索，不能把它宣称为已完整核实的纯成交指数。Ornn 主要是按需成交，排除长期预留；SemiAnalysis 静态表有历史所属期，本次没有验证动态图表刷新。
- 公司经营：GDS 面积利用率与 VNET 批发 MW、零售机柜口径不同。VNET 还区分成熟/爬坡及预留机柜调整；“上架率”是帮助搜索的别名，不构成同一分母。
- 宏观活动：国家能源局互联网数据服务用电不能直接转换成 GPU 利用率。Synergy 云基础设施包括 IaaS、PaaS 与托管私有云，不等于 GPU 租赁市场。
- 建设与市场：CBRE 重点市场机房租金采用美元/kW/月，不能与美元/GPU 小时相比。国家数据局全国规模、枢纽占比和平台接入规模各有范围和分母；算力精度须保留。
