# 第四轮受控发现词表

执行日：2026-10-12。仅用于人工选择候选与站内检索，不自动分类、不定时采集、不穷举请求。公司名称、别名和证券标识复用 Catalog 主体字典。

| 组别 | 发现词 |
|---|---|
| 行业 | IDC、AIDC、数据中心、智算中心、算力中心、AI数据中心、算力基础设施 |
| 租赁与需求 | 算力租赁、GPU租赁、智算服务、训练算力、推理算力、卡时、长协 |
| 项目运营 | 扩建、开工、交付、投运、机柜、IT容量、上架率、利用率、签约 |
| 资源配套 | 算电协同、绿电直连、接电、变电站、储能、备用电源、PUE |
| 技术 | 液冷、冷板、浸没式、模块化、超节点、光互连、异构调度、存储 |
| 公司动作 | 并购、重组、增资、融资租赁、重大合同、资产出售、战略合作、交割 |
| 英文 | data center、data centre、AI infrastructure、GPU cloud、GPU rental、colocation、hyperscale、commissioning |

按来源组合少量词。国家数据局查算力、枢纽、监测、算电协同及地方动态；媒体查数据中心、液冷、超节点、电源、上架率；公司披露查主体与报告/公告类型，不强制标题含IDC。英文供境外原站发现使用，不代表本轮每个词都发过请求。

审核候选时：

- IDC市场研究机构不等于数据中心运营商。证券代码必须对应发行主体。
- “不涉及算力租赁”只能作为业务澄清，不能标成已开展租赁；服务器销售也不能改为租赁收入。
- 泛行情、ETF推广、无关消费硬件、无实质业务信息的宣传不入库；涨停标题若包含真实合同仍应读原公告。
- 媒体采访可按媒体属性收录；方案、预测、厂商宣称不升级为交付、投运或收入确认。
- 标签仅来自本篇证据，不能继承来源介绍或其他文章。主类/子方向、地区、公司关联分别人工判断。
- 中国公司海外项目按项目实际国家；中文媒体报道美国事项仍标美国；全球/亚太不自动展开国家。
- 一篇跨地区资料只维护一个ID；转载同件补链接，同一事项不另建相同主证据节点。

本轮可复核样例：液冷/上架率→财联社9月13日报道；数据中心电源→每经9月24日欧陆通；超节点→36氪10月12日；存储/电力/散热→澎湃9月16日英特尔。正式记录仍保留媒体或厂商判断的限制。
