## 实际执行的检查

- `pnpm install --frozen-lockfile`：成功，原锁文件未改。
- Homer 基础构建与最终 `pnpm build`：均成功；最终日志 `build.log`。保留的上游动态导入有两条非阻断提示，详见 UPSTREAM.md。
- `pnpm validate`：成功，0 项数据结构错误；日志 `validation.log`。
- `pnpm test`：10/10 通过；日志 `tests.log`。
- 修改过的前端 Vue/JS 定向 ESLint：直接执行 `node node_modules/eslint/bin/eslint.js ...`，退出码 0。先前 pnpm exec 包装入口不可用，已改用安装包入口完成；没有运行自动修复全仓库。
- `pnpm preview --host 127.0.0.1 --strictPort`：生产产物 HTTP 预览成功。随后停止 Vite 预览，改由无依赖的 `node scripts/serve.mjs dist 5050` 提供最终入口。
- 首页和资料 JSON HTTP 均为 200；最终 JSON 使用 `Cache-Control: no-store`。构建资料与源资料 SHA-256 相同，构建许可证与源许可证相同。
